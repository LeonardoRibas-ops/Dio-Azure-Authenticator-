# 🧾 Boleto Authenticator – Azure Edition 🚀

Um projeto **Hands On** que valida boletos bancários como um ninja e ainda roda bonitão na nuvem com **Azure**. Tudo isso com uma pitada de **Node.js**, uma interface com **React** e deploy suave via **GitHub Actions**.

---

## 🛠️ O que é isso?

Este projeto cria um **serviço autenticador de boletos**, capaz de:
- Receber o código de barras de um boleto.
- Validar se é válido.
- Decodificar o valor e vencimento.
- Exibir tudo isso numa UI simpática.
- Rodar de forma automatizada no Azure.

Feito com ❤️ por um dev curioso e movido a café ☕.

---

## ⚙️ Stack usada

| Camada      | Tecnologia          |
|-------------|---------------------|
| Backend     | Node.js + Express   |
| Frontend    | React (com Vite)    |
| Deploy      | GitHub Actions      |
| Cloud       | Azure (App Service) |
| Infra       | Bicep/ARM Templates |
| Testes      | Jest                |
